# React + TypeScript + Vite

E-commerce platform developed with React and TypeScript, designed to offer a modern, intuitive, and visually appealing shopping experience. Upon entering, users are greeted by a hero slider highlighting promotions, products, and new arrivals. The interface is clean and minimalist, facilitating navigation and quick access to different sections such as products, shopping cart, favorites, and user profile.

## Main Features

- **Minimal and Responsive Design:** Modern, clean interface that adapts to any device.
- **Hero Carousel:** Main slider on the home page to highlight promotions and new products.
- **Product Gallery:** Display of products in a masonry format, with large images and clear descriptions.
- **Shopping Cart:** Add, remove, and adjust the quantity of products in the cart, with a purchase summary and subtotal.
- **Favorites:** Allows you to mark products as favorites and easily access them.
- **User Authentication:** Registration, login, and secure session management.
- **Admin Dashboard:** Product and user management, product creation and deletion, search, and filtering.

## Additional Considerations

- **Easy Extension:** The modular architecture allows for easy addition of new features or sections.
- **Best Practices:** Use of custom hooks, separation of logic and presentation, and strict typing.
- **Production Ready:** ESLint configuration, build and preview scripts, and environment variable management.
- **Accessibility:** Use of semantic tags and accessible navigation.
- **Internationalization:** The project can be easily adapted to other languages.
